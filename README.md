# MyFirstARProject!

A small augmented reality demo built with **Unity** and **Vuforia Engine**.

Link to video demo: https://youtube.com/shorts/plBsh6Z1sOw

## Image targets

The three printable image targets were **generated by Claude (Anthropic)** for this project:

- `target_1_letters.jpg`: scattered letters and symbols with a large **"1"** in the top-left
- `target_2_circuit.png`: right-angled circuit/maze lines with a large **"2"** in the bottom-right
- `target_3.png`: random circles and lines with a large **"3"** in the top-left

Both are A4 (2480 × 3508 px, 300 DPI), grayscale, and designed to be structurally different so Vuforia can tell them apart.
